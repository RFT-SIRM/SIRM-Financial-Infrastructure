# Security Policy

## Scope

This repository is a formal specification project. It is not yet a deployed chain or a production financial service. Security reports are still welcome for Lean definitions, workflow configuration, dependency handling, documentation that could cause unsafe use, and any future implementation.

## Reporting

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting / Security Advisories for this repository if that feature is enabled. If it is not enabled, contact the repository owner through a private channel before disclosing details publicly. Include affected commit, reproducible steps, expected impact, and any safe proof of concept.

## Response

Reports will be triaged for severity, affected versions, reproducibility, and potential impact. Do not assume a report is fixed until a reviewed commit and release explicitly state that it is fixed.
